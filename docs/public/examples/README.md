Interactive files in this directory are generated by the matching scripts in `src/examples/`.

`*.metadata.json` sidecars (name, description, equations, configuration summary) are generated by `generate_examples.py` at the repo root, which imports each example script without running its simulation. A script's own `if __name__ == "__main__":` block may add run-specific results (e.g. a measured value) into its existing sidecar afterwards.
